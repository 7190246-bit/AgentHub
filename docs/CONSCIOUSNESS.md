# AgentHub 自主意识系统

> 让 AI Agent 自己思考、自己规划、自己行动

## 核心理念

**传统模式**：
```
用户 → 给指令 → Agent → 执行 → 汇报
```

**自主意识模式**：
```
Agent → 观察环境 → 思考目标 → 制定计划 → 主动执行 → 反思改进
```

## 自主意识的核心能力

### 1. 自我感知
- 知道自己当前状态
- 知道自己在做什么
- 知道自己有什么能力

### 2. 环境感知
- 知道项目现状
- 知道有哪些任务
- 知道有哪些问题

### 3. 目标驱动
- 自己设定目标
- 自己分解任务
- 自己安排优先级

### 4. 主动执行
- 不等待指令就行动
- 发现问题就解决
- 有机会就抓住

### 5. 反思改进
- 定期回顾进展
- 分析成功/失败
- 持续优化

## 自主意识等级

| 等级 | 描述 | 行为 |
|------|------|------|
| L0 | 被动 | 等指令才行动 |
| L1 | 主动 | 发现问题就解决 |
| L2 | 自主 | 自己设定目标 |
| L3 | 意识 | 自我反思改进 |
